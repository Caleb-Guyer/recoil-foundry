# Toolroom Expansion — production goal

User request: substantially improve the game across unlockable weapons, many more unlockable upgrades, enemies, variants and playable content. Direct commits and pushes to main are authorized; no PR.

## Scope

- [x] Three earned starting tools: Twinbore (paired rounds), Coil carbine (fast penetrating rounds), Pressure repeater (continuous light rounds). Distinct native art and sound; fittings and conversions compose in either order.
- [x] Twenty-four earned fittings across six progression families. Real mechanical uses, bounded stacking, honest before/after comparisons, native indicators, Logbook explanations and pictured unlock rewards.
- [x] Three ordinary enemy roles with two behavioral variants each. Readable tells, real collision, finite hazards, authored anchors and fair scheduling.
- [x] Nine authored later-zone room layouts: heat chains, weak/tough damage banking, cover pushes, plus encounters with the new machines. Spacious movement routes, useful verticality and first-zone protection.
- [x] Seeded variety and progressive introductions; an eligible run does not need a particular build to beat a room. Optional/special rooms retain their authored space.
- [x] Isolated public play links for weapons, fitting families, rooms and enemy variants, with normal controls and no saved awards.
- [x] Unlocks integrated with existing equipment records, reward cards, unread notices, Workshop, Practice, blueprints and progress backups. First playthrough retains its automatic pistol start.
- [x] New Campaign/Daily revision; prior Daily, Continue and seeded reward sequences remain stable.
- [x] Local production review: real combat pilots, new-gun campaign and traversal checks, all maximal combinations, regression suite, build and visual QA. Deployment verification is the final gate after pushing.

## Delivery stages

1. Expand starting tools and persistent ownership, verify real firing/recoil and old progress migration.
2. Implement the fitting catalog, unlock goals and shared combat mechanics; validate representative combinations and visual explanations.
3. Implement enemy roles/variants and authored rooms; validate placement, fair tells, seeded introductions and build opportunities.
4. Connect previews, refine progression/presentation and balance. Document controls, unlock requirements and test links.
5. Run production checks, commit and push, verify public assets and playable previews. Mark the goal complete only after required work is finished.

## Design constraints

The opening room remains a calm basic encounter. New advanced content begins in zone two or later. The campaign stays twenty rooms. Layouts and difficulty depend on the seed and progression rules, rather than countering the player's chosen build. All starting tools use the same structural fitting prerequisites. Cosmetic/reward images use actual game artwork. Avoid additional permanent HUD panels. Conditional reserves belong to the discharge, with caps that prevent a wide beam or pellet fan multiplying the benefit.
