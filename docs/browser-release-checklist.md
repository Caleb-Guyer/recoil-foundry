# Full browser release checklist

**Closed for the 2.98.0 browser release · 20 September 2026.**

No required launch tasks remain. Completed work has been removed from this list. Future fixes and updates can continue; the Unity/Steam remake is a separate project.

The owner requested one final pass to finish the game after asking for best effort wherever tests could not be performed. Unavailable external player observations, human balance/duration acceptance and physical audio listening are **accepted release limitations**, not passed tests. Their status and the final verification evidence are preserved in the [release closeout](browser-release-closeout-2.98.0.md) and [support list](browser-support.md).

The complete browser scope is twenty rooms across five areas, 100 upgrades and branching builds, optional encounters and events, Daily runs, Overtime, Practice, Workshop, recaps/replays, Logbook, endings and cosmetic commendations. No further feature expansion is required for this release.
