# Ghost Races validation — 4.7.0

All **2,442 regular regression tests** passed, with no failures or skips. The final compact-recording validation and worst-case backup assertions then passed **73 focused race/trial/progress checks**, followed by a successful TypeScript/Vite production build. The existing eight maximal-build groups remain in the Pages deployment workflow. Vite reports the existing large shared-content chunk warning; the build completes successfully.

The 20 new race tests exercise actual traversal of all three courses with every unmodified starting gun. Recorded paths contain the real movement and ordered checkpoint times. Identical ordinary inputs with and without a ghost produce identical results, player positions, damage, shots, physics body counts and random streams. Pausing and hitstop freeze playback, recording and split expiry together. Cargo returns and early airborne landings discard the abandoned attempt's splits; playback does not interpolate across a cargo return. Menu and retry clear the previous race's transient state. Campaign, preview, death and forged-win fixtures cannot produce a recording.

Saved ghosts are bounded by duration, sample count, coordinate limits, real course entry/exit positions and exact field validation. Malformed compact paths, duplicates and incompatible identities are rejected. Nine maximum-size recordings round-trip through the existing one-megabyte backup limit with a Campaign checkpoint intact. Older backups without recordings migrate, and longer legitimate Practice clears can still share timing targets after their path recorder releases its frames. Codes and links round-trip course, gun and splits, reject hostile or mixed-mode data, enforce course/weapon access and retain their target on Retry. Shared challenges do not pay Campaign rewards or replace Continue.

Production-browser QA restored a separate localhost profile with recordings earned by the ordinary-input course simulations. The list displayed three matching bests, ghost markers and Share actions. Ghost toggling survived nested menu navigation. The share card showed a read-only code and link; Copy code produced the exact code with Copied feedback. Invalid input showed an error; a valid code opened the correct course/gun/time preview and started real ghost playback. Direct share-link entry, Retry, Pause and Menu worked while Campaign Continue remained available. The Pause label was corrected to Retry course and checked in the final rebuilt bundle. Course menus also fit a 480-pixel viewport. Restoring and Undo restore displayed the correct ghost counts and returned the temporary profile to its prior state. Locked course links disabled Start challenge, and malformed links opened recovery instructions. Browser warning/error logs were empty. The temporary viewport, tab and preview server were cleaned up.

Reproduce the focused checks with `node --experimental-strip-types --test tests/recoil-races.test.ts tests/recoil-trials.test.ts tests/progress.test.ts tests/maintenance-trials.test.ts`, the regular suite with `npm run test:ci`, and the production bundle with `npm run build`.
