# Recoil Foundry: Dead Signal — 3.0.0-rc.2

25 September 2026 · Staged release candidate · Daily ruleset 84

**The shift ended. The orders didn’t.**

The [Dead Signal content from rc.1](3.0.0-rc.1.md) is unchanged: take the alternate four-room Transmission Annex after Furnace, interrupt hostile transmissions, and use five Subversion upgrades to turn fallen machines into temporary allies. Six combat layouts, new machines, an original regional score and factory records give the route its own identity.

This candidate adds one quiet **Dead Signal / What’s new** button to the title screen. Its optional notes explain the route and upgrade family without revealing the boss. Back and Escape return focus to the link; no announcement opens automatically and no text is added to combat.

The [staged launch kit](../launch/dead-signal/README.md) includes three 1080p screenshots, a 23-second teaser with original music and game effects, a teaser cover, upload copy and a short launch-day announcement draft. These files are kept outside the playable site's bundle.

No gameplay, save, reward or Daily rules changed since rc.1. The [existing balance evidence](../plans/dead-signal-balance.md) remains applicable. This version distinguishes the new presentation from the preserved rc.1 archive.

**Not published.** This candidate stays on `feature/dead-signal`; the public reference remains `v2.98.1`. Host promotion, actual itch.io iframe/version checks and any available ordinary-player feedback remain release acceptance work. See [release operations](../release-operations.md).
