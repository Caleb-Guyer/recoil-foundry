# Your Next Goal — 5.2.0

The title screen shows one compact suggestion based on your saved progress. Select it to see the actual requirement, reward and where to start. Long descriptions stay in the details dialog; hunt and license counts appear only when they provide useful progress.

## Progression

The suggestion follows a stable order:

1. Beat the twenty-room Campaign through escape or factory shutdown.
2. Earn missing starting guns: Twinbore, Coil carbine, Pressure repeater and Burst nailgun. The first Campaign clear already earns the shotgun.
3. Clear Security I, II and III. Unlocking access to III alone does not count as beating it.
4. Earn remaining fitting licenses, using the existing boss, zone and electrical milestones.
5. Complete revealed commendations and earn their actual cosmetics.
6. Collect specific missing upgrades, choosing known prerequisite parts before their follow-ups and checking earned licenses.

Suggestions use real ownership and distinct hunt victories. They read existing saved progress and refresh on return to the title or a profile update. No new save category, checklist to maintain or changes to Campaign/Daily rules are needed. Your chosen gun, Security level and Continue run stay under your control.

Concealed machine and upgrade commendations keep their existing reveal requirements. A missing concealed boss challenge cannot produce a false completion message. After all tracked goals and all 141 upgrades are complete, the card acknowledges the core goals and suggests Daily runs, builds or personal records. Factory stories and other exploration remain available.

The normal suggestion stays out of Daily links, isolated playtests and shared challenge entries. At short window heights, the inline keyboard reminder yields space to the goal; Controls remains available. Goal details support keyboard activation and Back/Escape return to the same card.

## Validation

Fifteen goal tests exercise milestone transitions, actual weapon access, distinct hunt counts, Security completion, license priority, concealed challenges, strict preview URLs and side-effect-free selection. Every individual missing upgrade gets a discovery target; an end-to-end cleanup test collects the complete dependency graph without recommending an owned or locked fitting.

The targeted progression, save, weapon, Security, Logbook and longevity regression set passed 80 checks. TypeScript and the production build passed. The production preview was inspected at the native desktop size, 375 × 667 and 800 × 480, including keyboard opening, Escape focus return and later-profile goals. GitHub deployment remains gated on the full regular and eight-shard maximal-build suites.
