# Maintenance Trials — 3.12.0

Clear a Maintenance Shaft in a normal run to unlock its trials in **Practice → Maintenance Trials**. Only shafts you have cleared appear.

- Climb with the starting gun and full health. Retry repeats the same layout; New layout rolls another seeded climb.
- Finish to see your fastest climb and fewest shots. Each record keeps the time and shot count from the actual attempt. There is no timer on the HUD.
- Share a challenge link with a friend. It preserves the shaft, layout revision, seed and target time. Your friend must have earned that shaft too. Links open GitHub Pages and can also be imported from Maintenance Trials on itch.io.
- Complete clean climbs in both shaft types to earn **Servicewear**, a maintenance jacket with its own factory report. Normal runs and earned trials count; preview links do not. Equip it in Workshop → Appearance.

Trial records and unlocks are included in Progress backups and restore/undo. Trials leave the campaign checkpoint, upgrades, Daily records and boss Practice records untouched. Shaft unlocks begin with completions in this version, since earlier releases did not record them. Existing saves remain compatible; older unfinished shafts without damage history cannot claim a clean climb on Continue.
