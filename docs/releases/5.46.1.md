# 5.46.1 — Feedback draft retention

Feedback drafts now survive resuming the same attempt. Playtest answers, Bug, Difficulty and Suggestion text, the selected category, and edited or removed run details stay exactly as reviewed when the player returns to the form.

Drafts also stay with the attempt through ordinary room changes, including Quick Shift room loads and Gauntlet boss changes. Starting a new attempt, Retry, loading Continue from the title, resetting or changing a Workshop range, or returning to the title starts a fresh draft context.

Drafts remain in memory for the current attempt. Nothing is stored or posted automatically. Gameplay, player progress, checkpoint formats and Daily identities keep their existing rules.

## Validation

- Reproduced the original loss through Pause → Report → Back → Resume → Pause → Report.
- Browser checks cover all four feedback categories, selected-category retention, edited and empty summaries, same-seed Retry, title-screen reset, Campaign Resume and checkpoint Continue.
- Focused feedback and mode lifecycle tests, TypeScript, formatting and the production build pass. Publication requires the same commit to pass all regular-test and maximal-build jobs before deployment and packaging.
