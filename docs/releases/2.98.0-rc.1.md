# Recoil Foundry 2.98.0-rc.1

20 September 2026 · Browser release candidate · Daily ruleset 78

[Play](https://caleb-guyer.github.io/recoil-foundry/?v=2.98.0-rc.1) · [Support and limitations](../browser-support.md) · [Report an issue](https://github.com/Caleb-Guyer/recoil-foundry/issues/new?template=bug_report.md)

The complete browser content is available: twenty campaign rooms across five areas, 100 upgrades and branching builds, optional encounters, Daily runs, Practice, Workshop, Logbook, replays and more to discover. No shortened campaign or new content expansion is introduced by this release.

## Changes

- **Report an issue** is available from Settings and Pause. Review or edit the version, mode, seed, room, route and gun before opening a GitHub draft. Copy details is available too. No automatic telemetry, profile upload or issue submission.
- A concise player README replaces the development changelog landing page. The existing development history remains available separately.
- Three gameplay images, an 18-second silent gameplay clip and a social sharing card are included. The captures use the actual game simulation and renderer with scripted inputs; they are not human playtest footage.
- Release packaging, known limitations, an announcement draft and rollback instructions are documented.

This release follows the balance, first-session clarity, save recovery, settings, stability and presentation passes in 2.92.0–2.97.0. Gameplay balance and Daily identity are unchanged from 2.97.0. Existing saves and settings remain compatible.

## Supported target

Windows desktop/laptop, keyboard and mouse. Edge has the broadest owner verification. Chrome and Firefox basic gameplay is owner-confirmed, with narrower testing documented in the [support matrix](../browser-support.md). Controller/touch are experimental; macOS, Linux, Safari and low-end hardware have not been established as supported targets.

## Release status

**Release candidate, not final external acceptance.** No external first-time-player observations or physical speaker/headphone listening notes were available. Human difficulty, duration, readability and replayability judgments remain unverified. The owner requested best effort with available tools; no unavailable test is recorded as passed.

Known performance limits include an observed 141.7 ms stress hitch, an unresolved long-session embedded-browser slowdown, unknown low-end performance and uneven browser coverage. Replay export depends on browser recording capabilities. See the linked support list for evidence and workarounds.
