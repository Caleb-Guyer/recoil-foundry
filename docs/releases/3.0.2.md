# Recoil Foundry 3.0.2 — Feedback after a run

- **One quiet Feedback button** on death and victory screens, including Daily, Practice and test results.
- Choose **Bug**, **Difficulty**, or **Suggestion**. Each type has relevant prompts and its own GitHub issue template.
- Reports include editable version, mode, seed, room, route and owned upgrades. The chosen Annex/Cooling route is now identified explicitly.
- Switching types, returning to the result and reopening the form preserve your draft during that session. Starting gameplay again or returning to the title clears it. Drafts are not stored across reloads.
- Review the text before opening a GitHub draft, or use **Copy details**. A GitHub account is needed to post there. Nothing is submitted automatically.

The existing Settings/Pause report form uses the same categories. Gameplay, saved runs and Daily rules are unchanged.
