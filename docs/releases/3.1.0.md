# Recoil Foundry 3.1.0 — Overtime: Loading Docks

The first area of a newly entered Overtime run now has its own rooms, coordinated security teams and remixed boss arenas.

- **Transfer lock:** a moving freight platform splits the firing lanes; a shield escort arrives in the reinforcement wave.
- **Stamping aisle:** a fully warned crusher controls the central lane while a gunner and flyer coordinate a flank.
- **Broken dispatch:** the lower route has suspended cargo you can drop into the fight and a sniper/hopper ambush.
- **Counterweight gantry:** the upper route trades cargo for a tilting bridge and an airborne flanker.
- **Boss remixes:** the Loader gets a different arrangement of breakable supports and suspended loads; the Crane fights above a counterweight gantry. Both retain their existing attack warnings and finite support waves.

Each room focuses on one machinery type. Permanent floor routes and low obstacles keep the exits reachable with the starting gun. Layouts mirror with the run seed; retries restore the same encounter. There are no new combat HUD instructions.

New Overtime entries receive these rooms automatically. Previously saved Overtime runs retain their original layouts. The normal campaign, Daily rules, ordinary boss Practice, upgrade balance and later Overtime areas are unchanged. This is the first regional Overtime expansion.
