# See the Difference — 4.5.0

Upgrade rewards now have a shared gun comparison. Hover a choice or focus it with the keyboard/controller to see the current build beside the build with that upgrade added. Both ranges use the real Game, projectiles, physics, weapon art and world renderer. They fire, release stored shots, recharge, jump with recoil and aim at an actual wall. Fold builds place real portals. Conditional effects need their usual trigger; the range is a sample, rather than a damage benchmark.

Only changed values appear. Projectile comparisons distinguish per-pellet hits, firing cadence including native bursts, pellet and lane counts, recoil, wall banks, penetration, movement, kill healing and airborne bonuses. Beam and charged-lance comparisons use their firing cycle or charge time. Weapon conversions show the new firing behavior without presenting incomparable output as round damage. Conditional bonuses and secondary explosions stay in contextual descriptions, without an aggregate DPS score.

Combination hints describe prerequisites and fusions already on the player's gun, plus shared interactions such as Scattershot with Capacitor. Reforge compares against the current build and removes the exchanged fitting before adding its replacement. Field repair shows the actual capped health recovery.

The existing choice cards, numbered shortcuts and reroll flow remain usable. Inspection uses a single pair of canvases below the choices, and changing focus updates the comparison without accepting an upgrade. Nothing is added to the combat HUD. Reduced effects or the system's reduced-motion preference produces a still image. Hidden, inactive and offscreen previews stop advancing. Leaving or rebuilding the dialog disposes its ranges and event listeners; inspection does not change the real run, offers, seeded random stream, health, saves, unlocks or sound.

Isolated UI checks use `?test=upgrade-preview&build=basic&gun=pistol`, `?test=upgrade-preview&build=rail&gun=shotgun`, `?test=upgrade-preview&build=beam&gun=nailgun`, plus `stasis` and `shell` builds. These are actual reward screens and cannot record progress. See [validation](../validation/upgrade-preview-4.5.0.md).
