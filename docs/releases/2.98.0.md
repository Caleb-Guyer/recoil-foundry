## Playing and reporting

Use Windows desktop/laptop with keyboard and mouse. A/D moves, Space jumps, the mouse aims, and left click or F fires. Shoot downward while airborne to climb. Controls → Try controls provides a safe warm-up. Settings includes key bindings, separate sound/music levels, reduced effects and progress backups.

Settings or Pause → Report an issue lets you review version, seed, room and gun details before opening GitHub. Nothing is submitted automatically.

The downloadable ZIP contains the built static site. Extract it and serve the folder over HTTP; opening `index.html` through `file://` is not a supported way to run it. The [public play link](https://caleb-guyer.github.io/recoil-foundry/) needs no installation.

## Known limits and future updates

External first-time-player feedback and physical headphone/speaker listening were unavailable. The owner requested the final release using the best available checks; these remain unverified and are accepted as release limitations. Browser coverage varies, controller/touch are experimental, and low-end hardware support is not established. Documented stress hitches and embedded-browser slowdown are not claimed fixed. See [support and known limitations](../browser-support.md).

The browser game is complete within this scope. Future fixes, balance changes and additional content can still ship. The Unity/Steam remake is separate.
