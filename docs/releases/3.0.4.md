# Recoil Foundry 3.0.4 — Keep the good builds

- **Six named blueprints.** Open **Workshop → Builds** to save, rename, replace or load a gun. Finished run recaps can save their builds too.
- **Share codes.** Copy a blueprint code or preview one from a friend. Undiscovered upgrades stay unnamed and cannot be equipped; save the full blueprint for later or load only the upgrades you have collected, with their prerequisites.
- **Practice with a blueprint.** Load one through **Practice → a defeated boss → Workshop build → Builds**. If it exceeds that fight's upgrade limit, choose what to remove before starting. Your saved blueprint stays intact.
- Blueprints travel with **Settings → Progress** backups. Existing profiles and older backups gain six empty slots without losing progress.

Blueprints are for Workshop and earned boss Practice. They do not award discoveries or start campaign/Daily runs with extra upgrades. Combat balance, campaign checkpoints and Daily rules are unchanged.
