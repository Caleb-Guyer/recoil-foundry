# First steps — 5.7.1

The first room keeps one small, dismissible hint for the next action you have not learned: moving, jumping, firing, then using downward shots to climb. Actions learned early count immediately. Tips pause with the run, stop after the first room and stay quiet once those actions are learned; clearing the patrol points you toward the lit exit.

The first upgrade screen opens the first card's actual before/after gun comparison without selecting or purchasing it. Hovering or focusing another card changes the comparison, which stays visible when you move to the pictures. Reduced effects keeps the existing still-image comparison.

**Learn to play** remains on the title screen after the first session. It opens the existing safe pistol warm-up with real movement, recoil and targets, without replacing Continue or earning unlocks.

This patch includes Hunting Grounds 5.7.0, published on itch.io on 20 October. It does not change Campaign generation, Daily rules or weapon unlock requirements.
