# Playtest feedback — 5.7.2

The existing Feedback menu now includes a Playtest tab with three short questions: your best moment, the first confusing or frustrating moment, and what you actually did after dying and whether you wanted another run. An optional first-time/returning choice stays unanswered until you choose it. Short sessions, no deaths and stopping early are useful answers too.

An expandable run summary includes the current version, active run time, room, seed, starting gun and named upgrades. Active run time includes earlier play before Continue and excludes pauses; it is not a claim of a fresh ten-minute session. You can edit or remove the summary before copying.

Copy your feedback and paste it into the linked [itch.io playtest discussion](https://itch.io/t/7174290/recoil-foundry-free-browser-does-recoil-movement-make-sense-in-the-first-ten-minutes), or open a prefilled GitHub draft. Nothing is posted automatically. Answers stay in memory while you switch report categories or return to the menu; they are not saved across resumed gameplay or reloads. Bug, Difficulty and Suggestion remain available, with their own editable drafts.

The GitHub playtest templates use version-neutral titles and direct players to the current discussion. The guided first-session form remains available, alongside a template that accepts the report copied from the game.

## Test the flow

- [Open an isolated result preview](https://caleb-guyer.github.io/recoil-foundry/?test=presentation&scene=mastery&v=1), choose the preview button, then **Feedback**. Playtest opens by default. Edit answers, expand and redact the summary, switch to Bug and back, then copy. This preview grants no progress and does not replace Continue.
- [Open the isolated first room](https://caleb-guyer.github.io/recoil-foundry/?test=first-run&scene=opening&v=1), start the preview, then **Pause → Report an issue → Playtest**. The summary describes that run; issue reporting still opens on Bug.
- [GitHub guided first-session form](https://github.com/Caleb-Guyer/recoil-foundry/issues/new?template=first_ten_minutes.yml). Review the form without submitting a test issue.
