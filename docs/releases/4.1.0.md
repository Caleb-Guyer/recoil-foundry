# Starting Guns — 4.1.0

Choose a starting tool before a fresh Campaign:

- **Service pistol:** accurate single rounds with balanced recoil. The original gun keeps its stats.
- **Recoil shotgun:** five pellets, a much stronger kick and slower follow-up shots. Get close for full damage and use each shot to launch yourself.
- **Burst nailgun:** three precise nails followed by recovery, with smaller kicks. Burst upgrades shorten that recovery further.

Each tool uses the same upgrade pool without granting free upgrades or prerequisites. Scattershot adds pellets to the shotgun, and weapon conversions work with every starting tool. Continue, Retry, run replays and Workshop blueprints remember the choice. Workshop includes a starting gun selector; non-pistol shared builds use RF2 codes, while existing RF1 codes still load the pistol. Boss Practice keeps its original pistol for comparable challenge records.

New Daily challenges rotate a fixed starting gun by UTC date, shared by everyone. Daily ruleset 86 introduces these tools; rulesets 78–85 and older Continue saves keep the pistol.
